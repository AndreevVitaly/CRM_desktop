# PULSAR - Десктопная CRM для больницы

Нативное десктопное приложение для управления больничной CRM-системой.

## Установка

```bash
# Создать виртуальное окружение
python -m venv venv

# Активировать
venv\Scripts\activate  # Windows
source venv/bin/activate  # Linux/Mac

# Установить зависимости
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Тестовые учётные данные

```
# Регистратор

```

## Роли и права доступа

| Роль                | Код   | Права                                                                        |
| ------------------- | ----- | ---------------------------------------------------------------------------- |
| Администратор       | ADMIN | Полный доступ ко всем функциям                                               |
| Регистратор         | REG   | Создание/редактирование категорий АА, скрытие категорий АА, создание пользователей |
| Начальник отделения | LEAD  | Доступ к категориям АА своего отделения, управления планом лечения               |
| Работник                | DOC   | Доступ только к своим категориям АА, визиты, заметки, назначения                 |
| Делопроизводитель           | NUR   | Доступ к категориям АА своего отделения, визиты, заметки                         |

### Доступ к разделам

| Раздел       | Доступ |
| ------------ | ------ |
| Главный экран | все |
| Категории АА | ADMIN, REG, LEAD, DOC |
| Пользователи | ADMIN, REG, LEAD; для LEAD только свое отделение |
| КМ | ADMIN, REG; LEAD только свое отделение; DOC только свои записи |
| Статистика | ADMIN, REG; LEAD только свое отделение; DOC только свои данные |
| Документы | ADMIN, REG; LEAD и NUR только свое отделение; DOC только свои данные |
